# 数据管家 (Data Manager)

SillyTavern 第三方 UI 扩展。在一个面板里批量管理酒馆内的各类数据，删除前自动备份，可一键撤销或从历史还原。

## 功能

| 标签 | 删除 | 改名 | 编辑 JSON | 撤销/还原 |
|---|---|---|---|---|
| 预设（OpenAI/TextGen/NovelAI/Kobold/Instruct/Context/SysPrompt/Reasoning） | ✅ 批量 | ✅ | ✅ | ✅ |
| 世界书 | ✅ 批量 | ✅ | ✅ | ✅ |
| 角色卡 | ✅ 批量（可选连聊天一起删） | — | — | ✅（zip 备份 / 官方导入还原） |
| 用户设定 / 面具（Persona） | ✅ 批量 | ✅ | — | ✅ |
| 聊天记录（按角色筛选） | ✅ 批量 | ✅ | ✅ | ✅ |
| 主题美化 | ✅ 批量 | ✅ | ✅ | ✅ |
| 背景图片 | ✅ 批量 | ✅ | — | ✅（zip 备份 / 上传还原） |

其它：实时搜索筛选、全选/清空、单条导出、删除时自动下载备份、`🕘 历史`（持久化删除记录，可下载/还原）、**新建面具自动备份**、**可切换 4 套配色主题**。

## 安装

把 `st-data-manager` 整个文件夹放到：

```
SillyTavern/data/<你的用户名>/extensions/st-data-manager/
```

单用户部署通常是 `data/default-user/extensions/`。重启酒馆或刷新页面即可。也可以在扩展面板用 Install extension 填入仓库地址安装。

## 打开方式

- 顶部魔棒菜单 → 数据管家
- 扩展设置 → 🗂️ 数据管家 → 打开数据管家
- 聊天框输入 `/datamanager`（别名 `/dm`）

## 配色主题

面板顶部下拉可切换 4 套独立配色（星霜 / 暗玫瑰 / 深海 / 琥珀），不跟随酒馆主题，选中即记忆。

## 安全须知

- 删除是真删文件/条目，走酒馆官方接口。默认勾选「删除时下载备份」，会把整批内容存成单个文件到本地；即使关闭，也会写入本地「历史」，之后可下载或还原。
- 历史与备份存在**本浏览器**（IndexedDB），换设备或清理浏览器数据会丢失。想长期归档请另存备份文件。
- 删除面具/背景后，酒馆自身的对应列表可能需刷新页面才更新显示（数据已实际删除）。

## 兼容性

针对当前 SillyTavern release 分支接口编写，并对老版本做了兼容（如世界书列表优先用 `world_names`）。若某标签报「加载失败 404」，多为该版本接口路径不同——打开浏览器控制台看报错，改 `index.js` 对应 adapter 的 URL 即可。
